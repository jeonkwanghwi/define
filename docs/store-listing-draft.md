## 1. 앱 이름 · 부제 · 키워드

### 앱 이름 (30자 이내)

```
define — 나만의 정의
```

**`define` 단독은 권하지 않습니다.** App Store에 영어 사전 앱이 수십 개라 검색하면 묻힙니다.
한국 사용자는 한글로 검색하므로 한글을 붙이면 검색에도 잡히고 뜻도 전달됩니다.

대안:
- `define — 나만의 정의`  ← 추천
- `define : 내가 쓰는 뜻`
- `디파인 — 나만의 정의`  (한글 표기를 앞세우고 싶다면)

### 부제 (30자 이내)

```
사전이 아닌, 내가 쓰는 뜻
```

대안:
- `오늘의 단어를 나의 말로`
- `생각이 변하는 걸 기록하다`

### 키워드 (100자, 쉼표로 구분 · 띄어쓰기 금지)

```
정의,일기,기록,저널,단어,회고,생각,감정,사전,메모,마음,글쓰기,성찰,다이어리
```

**앱 이름·부제에 이미 들어간 단어는 키워드에 또 넣지 마세요** — Apple이 이름도 검색 대상으로 잡아서 중복은 낭비입니다. 위 목록에서 `정의`는 이름에 있으니 빼도 됩니다. 남는 자리에 `습관`, `자기이해`, `하루한줄` 같은 걸 넣을 수 있습니다.

## 3. 설명 (4000자)

> **첫 3줄만 펼치기 전에 보입니다.** 거기서 결판이 납니다.

```
우린 모두 각자의 정의가 있다.

사전은 '어른'을 "다 자란 사람"이라고 말합니다.
그런데 당신에게 어른은 무엇인가요?

define은 사전이 정해준 뜻 대신,
내가 생각하는 뜻을 직접 적는 기록 앱입니다.


■ 오늘의 단어

매일 하나의 단어가 찾아옵니다.
사랑, 시간, 실패, 퇴근, 첫사랑 ─ 누구나 한 번쯤 생각해봤지만
막상 정의해본 적은 없는 말들입니다.

관심사를 알려주시면 그에 가까운 단어가 더 자주 찾아옵니다.
마음에 들지 않으면 다시 뽑을 수 있습니다.


■ 생각이 변하는 걸 본다

같은 단어를 몇 달 뒤 다시 정의해보세요.
단어장에서 그때와 지금이 나란히 놓입니다.

"스물셋의 나는 사랑을 이렇게 썼구나."

변한 건 단어가 아니라 당신입니다.
그 변화는 다시 읽을 때만 보입니다.


■ 과거의 나와 대화

예전에 쓴 정의를 꺼내 그 시절의 나와 이야기할 수 있습니다.
그때의 문장과 말투를 바탕으로 대화가 이어집니다.

외부 AI를 쓰는 기능이라, 처음 시작할 때 따로 동의를 받습니다.
동의하기 전에는 어떤 내용도 밖으로 나가지 않습니다.


■ 다른 사람의 정의

광장에서 같은 단어를 남들은 어떻게 적었는지 볼 수 있습니다.
정답이 없다는 걸 확인하는 자리입니다.

공개되는 건 닉네임과 정의 글뿐입니다.
이메일, 나이, 성별은 누구에게도 보이지 않습니다.


■ 가입하지 않아도 됩니다

로그인 없이 바로 쓸 수 있습니다. 기록은 기기 안에만 남습니다.
가입하면 기기를 바꿔도 단어장이 따라오고, 광장에 참여할 수 있습니다.

가입은 카카오·Apple로 간단히 하거나 이메일로 할 수 있습니다.
카카오는 회원번호만, Apple은 계정 식별자만 받습니다.
이름도 이메일도 요청하지 않습니다.


■ 수집하지 않는 것

위치, 연락처, 사진, 광고 식별자, 기기 식별자를 수집하지 않습니다.
탈퇴하면 기록·좋아요·프로필·소셜 연결이 즉시 모두 지워집니다.


─────────────────────

개인정보처리방침
https://defineink.com/privacy.html

문의 definepjt@gmail.com
```

**확인하셔야 할 것** — 위 설명은 *지금 실제로 되는 것만* 적었습니다. 마을은 잠가뒀으니 넣지 않았고, 광고·잉크도 넣지 않았습니다(아직 실기기 검증 전). 기능이 추가되면 그때 설명을 늘리면 됩니다.

## 4. App Privacy (개인정보 보호) — 🔴 없으면 제출 불가

ASC → 앱 → **앱 개인정보 보호**에서 체크합니다. **개인정보처리방침과 한 줄도 어긋나면 안 됩니다.**

### 수집하는 데이터

| 데이터 유형 | 세부 | 목적 | 사용자에 연결 | 추적 |
|---|---|---|---|---|
| **연락처 정보** | 이메일 주소 | 앱 기능 | **예** | 아니요 |
| **사용자 콘텐츠** | 기타 사용자 콘텐츠 (정의 글·회상 대화) | 앱 기능 | **예** | 아니요 |
| **식별자** | 사용자 ID | 앱 기능 | **예** | 아니요 |
| **기타 데이터** | 출생연도·성별·관심사 | 앱 기능, 분석 | **예** | 아니요 |
| **사용 데이터** | 제품 상호작용 | **서드파티 광고** | 아니요 | 아니요 |
| **진단** | 기타 진단 데이터 | **서드파티 광고** | 아니요 | 아니요 |

**아래 두 줄은 AdMob 때문입니다.** 광고 SDK가 기기·사용 정보를 수집합니다 — 비개인화 광고라도 신고 대상입니다. **빠뜨리면 나중에 발각돼 앱이 내려갈 수 있습니다.**

### 추적(Tracking)

```
"이 앱은 사용자를 추적하지 않습니다"  ← 이쪽을 선택
```

ATT(앱 추적 투명성)를 구현하지 않았고 IDFA를 쓰지 않습니다. 광고는 **비개인화**로 나갑니다. 이건 개인정보처리방침의 "광고 식별자를 수집하지 않는다"와 일치합니다.

> ⚠️ 나중에 수익을 올리려고 개인화 광고를 켜면 **이 답과 방침을 둘 다 고쳐야** 합니다.

## 5. 연령 등급 설문

ASC의 설문에 이렇게 답하면 됩니다. 대부분 "없음"입니다.

| 항목 | 답 |
|---|---|
| 폭력·성적 내용·약물·도박 등 전부 | **없음** |
| **제한 없는 웹 접근** | 없음 (앱에서 외부 웹을 열지 않습니다 — 방침 링크만 예외) |
| **사용자 생성 콘텐츠** | **예** ← 광장이 있습니다 |
| 사용자 간 메시지 | 없음 (1:1 대화 기능 없음) |
| 위치 공유 | 없음 |

**사용자 생성 콘텐츠가 있어서 12+ 또는 17+가 됩니다.** Apple은 신고·차단 기능이 없으면 등급을 올립니다.

> 🔴 **확인 필요**: 광장에 **신고/차단 기능이 없습니다.** Apple 가이드 1.2는 사용자 생성 콘텐츠 앱에 ⒜ 불쾌한 콘텐츠 필터 ⒝ 신고 수단 ⒞ 차단 수단 ⒟ 연락처 공개를 요구합니다. **이게 리젝 사유가 될 수 있습니다.** 출시 전에 신고 버튼이라도 넣는 걸 권합니다 — 반나절이면 됩니다.

## 8. 스크린샷 — 사장님 몫

```
6.9"  1320×2868 또는 1290×2796   ← 이것만 올리면 나머지는 Apple이 자동 변환
최소 1장 · 보통 4~6장
```

**빌드 5를 설치한 폰에서 직접 찍으시면 됩니다.**

순서가 곧 설득 순서입니다:

1. **홈 — 오늘의 단어에 정의를 쓰는 장면** (가장 중요, 첫 장)
2. **단어장 — 같은 단어의 변화가 나란히 놓인 화면**
3. **광장 — 남들의 정의**
4. **회상 — 과거의 나와 대화**

찍을 때:
- 화면에 들어갈 **정의 글을 미리 좋은 문장으로** 채워두세요. 스크린샷의 내용이 곧 광고 문구입니다
- 상태바의 시간·배터리가 지저분하지 않게
- 다크 모드보다 **라이트 모드**를 권합니다 (브랜드의 따뜻한 종이 톤이 살아납니다)
