## 1. 앱 이름 · 부제 · 키워드

### 앱 이름 (30자 이내)

```
define — 나만의 정의
```

**`define` 단독은 권하지 않습니다.** App Store에 영어 사전 앱이 수십 개라 검색하면 묻힙니다.
한국 사용자는 한글로 검색하므로 한글을 붙이면 검색에도 잡히고 뜻도 전달됩니다.

대안:
- `define — 나만의 정의`  ← 추천
- `define : 내가 쓰는 뜻`
- `디파인 — 나만의 정의`  (한글 표기를 앞세우고 싶다면)

### 부제 (30자 이내)

```
사전이 아닌, 내가 쓰는 뜻
```

대안:
- `오늘의 단어를 나의 말로`
- `생각이 변하는 걸 기록하다`

### 키워드 (100자, 쉼표로 구분 · 띄어쓰기 금지)

```
정의,일기,기록,저널,단어,회고,생각,감정,사전,메모,마음,글쓰기,성찰,다이어리
```

**앱 이름·부제에 이미 들어간 단어는 키워드에 또 넣지 마세요** — Apple이 이름도 검색 대상으로 잡아서 중복은 낭비입니다. 위 목록에서 `정의`는 이름에 있으니 빼도 됩니다. 남는 자리에 `습관`, `자기이해`, `하루한줄` 같은 걸 넣을 수 있습니다.

## 3. 설명 (4000자)

> **첫 3줄만 펼치기 전에 보입니다.** 거기서 결판이 납니다.

```
우린 모두 각자의 정의가 있다.

사전은 '어른'을 "다 자란 사람"이라고 말합니다.
그런데 당신에게 어른은 무엇인가요?

define은 사전이 정해준 뜻 대신,
내가 생각하는 뜻을 직접 적는 기록 앱입니다.


■ 오늘의 단어

매일 하나의 단어가 찾아옵니다.
사랑, 시간, 실패, 퇴근, 첫사랑 — 누구나 한 번쯤 생각해봤지만
막상 정의해본 적은 없는 말들입니다.

관심사를 알려주시면 그에 가까운 단어가 더 자주 찾아옵니다.
마음에 들지 않으면 다시 뽑을 수 있습니다.


■ 생각이 변하는 걸 본다

같은 단어를 몇 달 뒤 다시 정의해보세요.
단어장에서 그때와 지금이 나란히 놓입니다.

"스물셋의 나는 사랑을 이렇게 썼구나."

변한 건 단어가 아니라 당신입니다.
그 변화는 다시 읽을 때만 보입니다.


■ 과거의 나와 대화

서로 다른 단어 20개를 정의하면 회상이 열립니다.
예전에 쓴 정의를 꺼내 그 시절의 나와 이야기할 수 있습니다.
그때의 문장과 말투를 바탕으로 대화가 이어집니다.

대화에는 잉크가 듭니다. 잉크는 매일 출석하거나,
꾸준히 기록하거나, 원할 때 광고를 보고 무료로 받을 수 있습니다.

외부 AI를 쓰는 기능이라, 처음 시작할 때 따로 동의를 받습니다.
동의하기 전에는 어떤 내용도 밖으로 나가지 않습니다.


■ 다른 사람의 정의

광장에서 같은 단어를 남들은 어떻게 적었는지 볼 수 있습니다.
정답이 없다는 걸 확인하는 자리입니다.

공개되는 건 닉네임과 정의 글뿐입니다.
이메일, 나이, 성별은 누구에게도 보이지 않습니다.
불쾌한 글은 신고하고, 보고 싶지 않은 사람은 차단할 수 있습니다.


■ 가입하지 않아도 됩니다

로그인 없이 바로 쓸 수 있습니다. 기록은 기기 안에만 남습니다.
가입하면 기기를 바꿔도 단어장이 따라오고, 광장에 참여할 수 있습니다.
가입하면 그동안 쓴 정의도 광장에 함께 올라갑니다.

가입은 카카오·Apple로 간단히 하거나 이메일로 할 수 있습니다.
카카오는 회원번호만, Apple은 계정 식별자만 받습니다.
소셜 로그인으로 가입하면 이름도 이메일도 요청하지 않습니다.


■ 수집하지 않는 것

위치, 연락처, 사진을 수집하지 않습니다.
광고는 비개인화 광고로만 보여주고, 앱 추적 허용을 묻지 않습니다.
탈퇴하면 기록·좋아요·프로필·소셜 연결이 즉시 모두 지워집니다.


———

이용약관
https://defineink.com/terms.html

개인정보처리방침
https://defineink.com/privacy.html

문의 definepjt@gmail.com
```

**2026-10-18 고친 것** (약 1,300자 — 4,000자 한도 안):
- "이메일로 할 수 있습니다" 뒤에 "이름도 이메일도 요청하지 않습니다"가 와서 **서로 모순**이었다 → "**소셜 로그인으로 가입하면** 이름도 이메일도 요청하지 않습니다"로 범위를 좁혔다.
- "광고 식별자, 기기 식별자를 수집하지 않습니다" → 광고 SDK(AdMob)가 기기 정보를 직접 수집하므로 앱 전체로는 참이 아니다. **"비개인화 광고만, 앱 추적 허용을 묻지 않음"**으로 바꿨다(방침 v1.2와 같은 말).
- 회상 **열림 조건(서로 다른 단어 20개)**과 **잉크(출석·연속 기록·광고)**를 넣었다 — 심사자가 회상 탭에서 막히면 "기능이 안 된다"로 읽는다.
- 광장에 **신고·차단** 한 줄, 가입 시 **기존 정의가 광장에 올라간다**는 한 줄(앱 문구와 같은 사실)을 넣었다.
- 이용약관 링크 추가.
- ASC는 설명에 `─`(상자 그리기 문자)를 거부한다 → `—`로.
- **마을은 1.0에서 탭을 숨기므로 설명에 넣지 않는다.** 스크린샷에도 마을이 없어야 한다 — **🔴 현재 올린 4장은 하단 탭바에 '마을'이 보인다**(§8).

## 4. App Privacy (개인정보 보호) — 🔴 없으면 제출 불가

ASC → 앱 → **앱 개인정보 보호**에서 체크합니다. **개인정보처리방침과 한 줄도 어긋나면 안 됩니다.**

### 수집하는 데이터

| 데이터 유형 | 세부 | 목적 | 사용자에 연결 | 추적 |
|---|---|---|---|---|
| **연락처 정보** | 이메일 주소 | 앱 기능 | **예** | 아니요 |
| **사용자 콘텐츠** | 기타 사용자 콘텐츠 (정의 글·회상 대화) | 앱 기능 | **예** | 아니요 |
| **식별자** | 사용자 ID | 앱 기능 | **예** | 아니요 |
| **기타 데이터** | 출생연도·성별·관심사 | 앱 기능, 분석 | **예** | 아니요 |
| **사용 데이터** | 제품 상호작용 | **서드파티 광고** | 아니요 | 아니요 |
| **진단** | 기타 진단 데이터 | **서드파티 광고** | 아니요 | 아니요 |

**아래 두 줄은 AdMob 때문입니다.** 광고 SDK가 기기·사용 정보를 수집합니다 — 비개인화 광고라도 신고 대상입니다. **빠뜨리면 나중에 발각돼 앱이 내려갈 수 있습니다.**

### 추적(Tracking)

```
"이 앱은 사용자를 추적하지 않습니다"  ← 이쪽을 선택
```

ATT(앱 추적 투명성)를 구현하지 않았고 IDFA를 쓰지 않습니다. 광고는 **비개인화**로 나갑니다(`requestNonPersonalizedAdsOnly: true`). 개인정보처리방침 v1.2(2026-10-18)는 이 사실과 AdMob이 직접 수집하는 항목을 함께 적었습니다.

> ⚠️ **확인 필요 — 위 표가 Google 공개 목록보다 좁다.** Google의 [AdMob 데이터 공개 가이드](https://developers.google.com/admob/ios/privacy/data-disclosure)는 SDK가 기본으로 **IP 주소(대략적 위치)·충돌 로그·성능 데이터·기기 ID(광고 ID 또는 앱 단위 기기 ID)·광고 데이터·제품 상호작용**을 수집한다고 적는다. 위 표에는 사용 데이터·진단만 있다. **위치(대략적 위치)·식별자(기기 ID)·사용 데이터(광고 데이터)**를 "서드파티 광고, 사용자에 연결 안 됨, 추적 안 함"으로 추가할지 ASC 입력 전에 결정해 주세요. 넣는 쪽이 안전하다(빠뜨린 쪽이 발각돼 내려가는 쪽).

> ⚠️ 나중에 수익을 올리려고 개인화 광고를 켜면 **이 답과 방침을 둘 다 고쳐야** 합니다.


2026-10-17에 4장을 올렸다 — 파일과 고른 이유는 [store-screenshots/README.md](./store-screenshots/README.md).

> 🔴 **다시 찍어야 한다.** 4장 모두 **하단 탭바에 '마을' 탭이 보이고**, 포인트 색이 지금의 호박색이 아니라 **옛 남색**이다. 1.0에서 마을 탭을 숨기면 스크린샷이 실제 앱과 달라져 **2.3.3(스크린샷이 실제 앱을 보여줘야 함)** 리젝 사유가 된다. 마을을 숨긴 빌드로 같은 구도 4장을 다시 찍을 것.

순서가 곧 설득 순서입니다:

1. **홈 — 오늘의 단어에 정의를 쓰는 장면** (가장 중요, 첫 장)
2. **단어장 — 같은 단어의 변화가 나란히 놓인 화면**
3. **광장 — 남들의 정의**
4. **회상 — 과거의 나와 대화**

**마을은 찍지 않는다** — 1.0에서는 탭을 숨긴다. 탭바에 보이는 것도 안 된다. 앱에 없는 화면이 스크린샷에 있으면 2.3.3 리젝 사유다.

찍을 때:
- 화면에 들어갈 **정의 글을 미리 좋은 문장으로** 채워두세요. 스크린샷의 내용이 곧 광고 문구입니다
