## 1. 서비스 개요

| 항목 | 내용 |
|------|------|
| 서비스명 | **define** |
| 슬로건 | 우린 모두 각자의 정의가 있다 |
| 한 줄 정의 | 사전적 정의가 아닌, 내가 직접 정의하는 나만의 단어 백과사전 |
| 핵심 가치 | 같은 단어에 대한 생각이 시간에 따라 변하는 흐름을 기록하고, 과거의 나를 회고하게 만드는 경험 |

### 디자인이 풀어야 할 핵심 과제
사용자가 "단어를 정의하는 행위"를 **부담 없이, 그러나 의미 있게** 느끼도록 만드는 것. 일기처럼 무겁지 않고, 메모처럼 가볍지만, 다시 들춰봤을 때 울림이 있어야 한다.

## 2. 브랜드 톤 & 무드

### 정서적 방향
사색적이고 차분하되, 무겁지 않게. 사용자가 자기 내면을 들여다보는 순간을 돕는 도구이므로, 화려함보다 여백과 타이포그래피로 승부한다. "노트", "잉크", "사전"의 정제된 느낌과 현대적 미니멀리즘의 결합.

### 무드 키워드
차분함 · 사색 · 여백 · 기록 · 성장 · 정제됨 · 따뜻한 미니멀

### 톤에서 피해야 할 것
과도한 그래디언트, 자극적인 네온, 게임처럼 시끄러운 UI, 정보 과밀.

### UI/UX 원칙 (사용자 명시)
**"부드럽고 세련된 사용감"이 모든 기능 앞에 온다.** 시스템 다이얼로그(Alert/ActionSheet) 사용 금지. 모든 상태 전환은 부드러운 트랜지션(180-250ms). 마이크로 인터랙션으로 만족감 강화. 기능 작동만으로 마무리하지 말 것.

#### 🌊 "부드러움"은 상시 원칙 (2026-07-02 사용자 명시 — 항상 적용)
> **모든 측면에서 항상 "스르륵 넘어가는" 부드러움을 느끼게 한다.** 새 화면·컴포넌트·상호작용을 만들거나 고칠 때, 아래를 **기본값으로** 넣는다(빼먹으면 미완성):
> - **화면 전환** — 뚝 끊기지 않고 부드럽게 슬라이드/페이드.
> - **버튼·카드 누름** — 살짝 눌리는 느낌(scale/색 전환), 즉각 반응.
> - **드롭다운·시트·세그먼트** — 부드럽게 열리고 닫힘, 튀지 않게.
> - **콘텐츠 등장** — 리스트·카드·대화 답변은 툭 뜨지 않고 fade-in으로 스르륵. (회상 답변 = **통째 fade-in**만 우선, 토큰 스트리밍은 후속.)
> - **상태 변화** — 로딩→내용, 값 변경 등도 보간.
>
> 톤 가드: 부드럽되 **조용하게**(§ "게임처럼 시끄러운 UI 지양"과 균형). 과한 bounce·요란한 연출 X, 절제된 스르륵. 구현 규칙은 [DEVELOPMENT.md](./DEVELOPMENT.md) §5 모션 시스템 참조.

## 4. 정보 구조 (IA)

```
하단 탭바
├── tab1 광장 (단어 → 사람: 단어로 타인의 정의 보기)
├── tab2 마을 (사람 → 단어: 사람으로 진입해 그 사람의 단어 보기) — 확정, 렌더링은 2D~2.5D 프로토 먼저
├── 중앙·메인 기록 (단어 기록하기)   ← 핵심 행동
├── tab3 과거의 나 (회상: 그 시절 정의로 페르소나 생성·대화)
└── tab4 단어장 & 통계
헤더 우상단: 마이페이지
```
> **명칭 정리(2026-06-20, 갱신 2026-06-30 = 코드 라벨에 정합)**: 하단 탭 = **tab1 광장**(`plaza`) · **tab2 마을**(`village`) · **중앙·메인 기록**(라벨 "기록", 코드 `index`) · **tab3 과거의 나**(라벨 "과거의 나", 기능 통칭 **"회상"**, 코드 `past`) · **tab4 단어장**(라벨 "단어장", 코드 `journal`). ※ "저널/journal"은 tab4 *코드명*, 라벨은 "단어장" — 메인 "기록"과 안 겹침. ※ tab3 구 가칭 **"타임머신"은 폐기**. ※ **"1·2·3차" 식 표현은 개발 단계(회차)** 를 뜻하며 탭 번호가 아님 — 문서에선 **"N단계"** 로 표기. **재화명**: **"잉크" ✅ 확정**(2026-06-28, 가제 해제; 구 가칭 "루비"). 코드 식별자는 중립어 `balance`(표시만 "잉크"), 색 액센트 토큰은 아직 `ruby`(#D6456A) — 이름 정합 정리는 후속.

> 중앙 메인 탭은 chip 모양 강조로 시각적으로 도드라지게 처리. ✅ 구현 완료.
> 화면별 상세 기능 명세는 [DEVELOPMENT.md](./DEVELOPMENT.md) 참조.

### 탭별 핵심/확장 메모

- **[중앙·메인] 기록** ✅ — 오늘의 추천 단어(서버 지정 풀에서 오늘 아직 정의 안 한 단어 랜덤) · 새 단어 뽑기 · 커스텀 단어 추가.
  - **회의 확정(2026-06-15)**: 첫 화면에서 **내 아바타가 단어를 나에게 물어보는** 형태로 제시 — 예: "사랑이란 무엇인가요?" (마을 아바타와 연결되는 캐릭터 연출. 기존 단어 카드 → 아바타 질문 UI로 발전.)
  - 확장①: **금주의 단어** — 매주 1개를 정해 모두가 보는 공개 공간에 댓글이 쭉 달리는 형태.
  - 확장②: **AI 정의 이미지/영상화** — 작성한 정의를 AI가 이미지·영상으로 생성 → 타인의 정의를 릴스式으로 내려보며 감상(캡션으로 어떤 단어인지 맞히기 / 단어 검색 시 관련 영상·정의를 피드로).
- **tab1 광장** 🟡(백엔드) — 단어에 대한 타인의 생각 보기(상호주의). 두 컨셉 검토 중:
  - **컨셉1**: 단어 중심(현재 형태) — 단어별로 여러 사람의 정의 카드.
  - **컨셉2**: 싸이월드式 — 사람을 클릭해 그 사람의 "방 + 아바타 + 정의 목록"으로 진입.
  - 댓글은 일단 없음. **신고 시스템** · **추천(좋아요)** + 추천순 정렬(내 정의는 항상 맨 위 하이라이트).
- **tab2 마을** 🟡 — **탭명 "마을" 확정**(아바타 마을 = 광장 컨셉2 승격). **렌더링은 2D~2.5D 수준으로 먼저 프로토타입 구현 → 퀄리티 다같이 보고 결정**(2026-06-15 회의). 3D는 그 뒤 판단. (대체 후보였던 오늘의 기분/검색/주간 회고는 보류.)
  - 🔴 **방향 대전환(2026-06-28 회의) — 마을/방/아바타 이미지를 시스템 프리셋 파일이 아니라 *사용자 메모 기반 AI 이미지 자동 생성*으로 채운다. "그 사람의 메모가 곧 마을의 이미지."** 기존 자산 접근(2D 픽셀아트·CC0 에셋·렌더러·컨셉 이미지 프롬프트)을 **사실상 대체** → 별도 설계 사이클 필요(생성 파이프라인·비용·저장·생성 시점·아이템 데이터 모델). **함의**: 마이페이지에 "단어 기록 보기" 외 **"아이템 보기"** 추가 — 아이템 탭 시 *어떤 메모로 이 아이템이 생성됐는지*(원본 메모) 역추적(아이템 = 메모로 생성된 마을 오브젝트). ※ 아래 2026-06-15 확정 기능 상세는 이 전환 위에서 재해석 필요.
  - **아바타 마을**: 탭1 광장이 "**단어 → 사람**"(단어로 타인의 생각 보기)이라면, 탭2는 "**사람 → 단어**"(사람으로 진입해 그 사람의 단어 보기). 내 아바타가 맵을 돌아다니며 집(=각 유저)에 들러 그 사람의 정의를 들여다봄. 아바타·집은 **루비로 꾸밈**(BM §6 공간/아바타와 연동). 싸이월드 감성.
  - **회의 확정 — 기능 상세 (2026-06-15)**:
    - **내 공간 구조(확정)**: **"내 집"이 있다** — 내가 직접 짓고 꾸미는 고정 공간(남이 방문). + 돌아다니며 만나는 집은 **랜덤 타인**(새로고침마다 교체). 싸이월드/동물의 숲式.
    - **두 단계 구조**: ① 마을을 **돌아다니며 집을 고름** → ② 집을 고르면 **그 사람 집에 입장**해 꾸며놓은 것 + 단어들을 봄.
    - **집 새로고침**: 돌아다니며 마주치는 집은 **새로고침하면 다른 사람들로 교체**(매번 다른 이웃 셋). + **필터** 가능 — **나이·성별·관심사** 등으로 보고 싶은 이웃 좁히기. (필터 데이터 = 가입 시 수집, 아래.)
    - **건물 "설치 시간"(대상=건물 짓기)**: 내 공간에 **건물을 짓는 것**에 시간이 걸리게 함(즉시 X) → 설치 끝나면 **유저가 다시 와서 보게 유도(재방문 루프)** + **루비로 설치 시간 단축**(과금 유도, BM §6).
    - **캐릭터 이동 연출**: 아바타가 직접 움직이되 **잔상 효과·효과음** 등으로 움직임 자체에 재미. (⚠️ 브랜드 "차분/시끄럽지 않게"와 균형 필요 — 톤 가드 아래 참조.)
    - **화면 방향**: 마을은 **세로(portrait)** 로 사용. (가로 전환 없음.)
  - **핵심 설계 원칙(확정 방향)**: **실시간 멀티 아님 — 비동기 월드.** 내 아바타만 움직이고, 남들은 "방문 가능한 집(실제 유저의 스냅샷)"으로 정적 존재. 살아있는 아바타 동기화는 비용·난이도 최상위라 의도적 배제(싸이월드도 실시간 아니었음). → 가치 90%를 비용 10%에.
  - **기능 범위(확정 경계)**:
    - ✅ **포함**: 내 아바타만 이동·조작 / 남은 정적 집(NPC) / 집 입장 → 그 사람의 단어장 열람 / 아바타·집 루비 꾸미기.
    - 🔓 **미래 가능(비동기)**: 남의 집에 **방명록·쪽지** 남기기. 실시간은 아니지만 싸이월드 감성에 부합 — 백엔드 도입 후 추가 가능한 옵션으로 열어둠.
    - ❌ **배제**: 실시간 채팅 / 살아있는 타인 아바타 / presence 동기화 (websocket 류, 비용·톤 부적합).
    - ⚠️ **데이터 출처**: 집 안의 "그 사람 생각" = 가짜(mock)면 지금도 연출 가능, **실제 타인 정의면 백엔드·계정·광장 공유 필요.**
  - **톤 주의**: 브랜드는 "게임처럼 시끄러운 UI" 지양. 액션 게임이 아니라 **느리고 정적인 산책형 마을(동물의 숲 같은 차분함)**로 풀어야 톤과 충돌 안 함.
  - **선행 조건(= 보류 이유)**: 백엔드·회원가입·광장 공유(상호주의)·루비 경제(서버 권위)가 전부 먼저 서야 "진짜 기능"이 됨. 탭1보다 더 백엔드 의존적. 상세 타당성은 [DEVELOPMENT.md](./DEVELOPMENT.md).
- **tab3 과거의 나 (회상)** (구 가칭 "타임머신·과거의 나와 대화") 🔴(GPT) — "N살의 나"(그 시절 정의로 페르소나 생성). + **익명의 타인과 대화/생각 보기**(공개/비공개 상호주의 연동) + **사진 기반 talking-video**(올린 사진이 움직이며 대화).

## 5. 핵심 정책 & 규칙

### 광장의 상호주의
"내 생각을 공유해야 다른 사람들의 생각을 읽을 수 있어요." 비공유 사용자에게는 잠금/블러 상태로 노출하고 공유를 유도. 공개/비공개 토글로 양방향 제어. ("나 비공개 & 타인도 못 봄" ↔ "나 공개 & 타인 것도 볼 수 있음" 택1)

> 🔴 **현재 구현 ≠ 위 정책 (2026-07-21 감사)**: 지금은 **로그인 = 전체 열람**이다. 광장 게이트는 순수 **가입 게이트**(`AuthGate`가 token만 확인) — 정의 0개인 유저도 로그인만 하면 타인 정의를 다 본다. **상호주의(공유 조건부 열람)·블러·공개/비공개 토글 모두 미구현.** 게이트 문구("가입하고 내 정의를 나누면 광장이 열려요")는 공유를 *암시*만 할 뿐 강제하지 않는다. 또한 **가입 시 로컬 정의가 자동으로 서버 동기화되어 광장에 공개되는데, "당신의 정의가 공개됩니다"라는 명시적 고지가 없다**(공개 방향 무고지 — 프라이버시 관점). → §8 항목.

### 광장 운영 정책
- **댓글**: 초기엔 비활성(읽기 중심). 추후 도입 검토.
- **신고 시스템** + 모더레이션 필요 — **광장 3단계**(2단계 좋아요 다음)로 예정. 신고 누적 모니터링 · 임계값 자동 조치(기록 숨김/삭제 · 유저 차단) · (추후) AI 사전 감지는 §8 참조.
- **추천(좋아요)** 기능 + 추천순 정렬. 단 **내 정의는 항상 맨 위에 하이라이트**.
- 표시 컨셉(단어 중심 vs 싸이월드式 방·아바타)은 미확정 — IA 4장 참조.

### 기록의 시간 정책
오늘이 기본값, 과거 날짜 선택 가능, 미래 날짜 선택 불가. ✅ 구현 완료.

### 추천 단어 정책
서버가 지정한 '오늘의 추천 단어' 풀에서, 사용자가 오늘 아직 정의하지 않은 단어를 랜덤 노출. (현재는 로컬 풀에서 랜덤, 백엔드 도입 시 서버 풀로 교체.)

### 단어 정규화(canonical) 정책
**시스템 정의 단어**(추천 풀·광장 클러스터링의 기준점)와 **사용자 정의 단어**(사용자가 직접 쓴 정의)를 구분한다. 사용자가 추천 풀에 없는 단어를 직접 추가할 때, 풀에 **의미가 유사한 단어가 있으면** "이걸로 모을까요?"를 1회 제안한다.
- 같다고 하면 → 기존 **시스템 단어로 모음** (광장에서 한 단어 아래 정의가 쌓임).
- 다르다고 하면 → 사용자 주관을 존중해 **그대로 추가**.
- **강제 병합은 하지 않음** (첫 정의는 가볍게 — 유사어 있을 때만 노출).

목적: 광장에서 의미가 같은 단어가 "행복 / 행복함 / 행복이"로 파편화되는 것을 막아 "남들은 이 단어를 어떻게 정의하나" 가치를 보존. 유사도 판별 방법(알고리즘)은 [DEVELOPMENT.md](./DEVELOPMENT.md) 참조(미확정).

### 익명 사용자 모델 + 탭 게이팅 (✅ 확정 2026-06-06)
**인증 모델 확정**: 3안 중 **① 익명우선** 채택 (회의 결과). 회원가입 없이도 **핵심 기능(단어 작성)** 을 바로 쓰고 폰에 영구 누적(로컬 영속). 회원가입은 **타인·서버가 필요한 기능을 만나는 순간** 자연스럽게 유도.

**탭별 게이팅 정책** (좌→우 현재 탭 기준):
| 탭 | 회원가입 | 이유 |
|----|:---:|------|
| 광장 (`plaza`) | **필요** | 타인의 정의 = 서버·계정·상호주의 |
| 마을 (`village`) | **필요** | 타인의 집/아바타 = 서버·계정 |
| **기록 (`index`, 중앙·메인)** | **불필요** | 핵심 행동. 로컬에 저장 |
| 과거의 나 (`past`) | **필요** | GPT 페르소나·서버 |
| 단어장·통계 (`journal`) | **불필요** | 내 로컬 데이터만 읽어 표시 |

- **게이팅 방식**: 가입 필요 탭은 **숨기지 않고** 진입 시 가입 유도(잠금/블러) 화면 노출 → 광장 상호주의 정책(§ 위)과 일관, 기능 존재를 보여 전환 유도.
- **동기화**: 회원가입 시 로컬 `SavedEntry[]`를 서버로 1회 업로드(`POST /api/journal/import`). flat 모델이라 마이그레이션 단순.

## 9. 타겟 유저 / 페르소나 (Persona)

> **확정 방향**: 나이·성별이 아니라 **성향(내면·사색·기록)**으로 타겟을 묶는다. 연령 폭 20~40, **성별 균형(중립)**.
> 폭넓은 타겟의 초점 흐림 위험은 아래 *공통 심리 코어 + 대표 페르소나 + 안티 페르소나*로 좁힌다.

### 한 줄 타겟
> 자기 내면을 들여다보고, 생각을 **가볍게** 기록하며, 시간이 지나 그 **변화를 회고**하고 싶은 **20~40대 사색가**. 나이·성별보다 *기질*로 정의된다.

### 공통 심리 코어 (psychographic) — 모든 페르소나가 공유
- 자기 내면·생각에 관심이 많다 (introspective)
- 본격 일기·저널링은 부담스러워한다 → **저마찰 진입**을 원한다
- 성장·변화·회고에서 의미를 느낀다
- 감성 문장·글귀·정제된 언어에 반응한다
- 과시보다 **조용하고 사적인 기록**을 선호한다

### 대표 페르소나 3 (연령 스팬, 성별 중립)
연령대만 다를 뿐 위 코어를 공유한다.

- **P1. 막 시작하는 기록자 — 20대 중반**: 일기 앱을 여러 번 깔았다 지웠다, 꾸준함이 늘 숙제. SNS 감성 글귀를 소비·저장. → *"부담 없이 한 단어로 시작해, 이번엔 꾸준히 남기고 싶다."*
- **P2. 변화를 회고하는 사람 — 30대 초·중반**: 바쁜 일상 속 가끔 멈춰 자신을 돌아봄. 몇 년 전의 나와 지금의 차이가 궁금. → *"과거의 내가 어땠는지, 내가 정말 성장했는지 확인하고 싶다."*
- **P3. 사색을 즐기는 깊은 기록자 — 30대 후반~40대**: 책·글·사유를 즐기고 단어의 의미를 곱씹음. 싸이월드 향수도 약간. → *"내 생각을 정제된 언어로 남기고, 남들은 이 단어를 어떻게 정의하는지 엿보고 싶다."*

### 핵심 JTBD (Jobs-To-Be-Done)
1. 가볍게 내 생각을 남긴다 (저마찰 기록)
2. 과거의 나를 회고하고 성장을 확인한다
3. "남들은 이 단어를 어떻게 볼까" — 조용한 호기심·공감
4. 정제된 언어로 나를 표현한다

### 안티 페르소나 (이 앱이 *아닌* 사람) — 초점 유지용
- 빠른 도파민·경쟁·게임성을 원하는 사람
- 공개 팔로워·좋아요로 인정받고 싶은 사람
- 할 일 관리·실용 정보 도구를 찾는 사람
- 매일 길게 쓰는 *본격* 저널링을 원하는 사람 (우리의 핵심은 **가벼움**)

### 페르소나가 못 박는 제품 결정 (So-What)
- **온보딩**: 회원가입 강요 X → 한 단어로 즉시 시작 (익명 로컬 모델 §5와 일치)
- **톤**: 조용·사적·정제 → 과시·경쟁·시끄러운 게임성 배제 (브랜드 톤 §2와 일관)
- **광장**: 과시 피드가 아니라 "조용한 엿보기·공감" (상호주의 §5)
- **게이미피케이션**: 잉크·출석을 전면에 과하게 X. 단 **마이페이지 잔액 카드 + 메인 헤더의 절제된 잉크 칩**까지는 허용(2026-06-28 결정) — 게임적 강조(큰 배지·애니메이션 남발) 금지, 조용한 톤 유지.
- **마케팅**: 메시지를 *나이*가 아니라 *기질*("기록·회고·성장")로 소구

### 2026-07-21 — 감사 제기: 광장 상호주의 고지·구현 갭 (정책 vs 현실)
- **무엇**: "광장 들어가기 전에 내 것을 먼저 공유해야 함을 고지하나?" 점검 → **고지 안 하고, 요구하지도 않음.** 광장 게이트는 순수 가입 게이트(로그인=전체 열람), 상호주의·블러·공개/비공개 토글 모두 미구현. 게이트 문구("가입하고 내 정의를 나누면 광장이 열려요")는 공유를 암시만 하고 강제 X.
- **더 중요한 발견(프라이버시)**: 가입 시 로컬 정의가 **자동으로 서버 동기화→광장에 타인 공개**되는데, "당신의 정의가 공개됩니다"라는 **명시적 고지가 없음**(공개 방향 무고지). 상호주의 미고지보다 우선 처리 권장.
- **반영**: §5 광장의 상호주의에 "🔴 현재 구현 ≠ 정책" 블록, §8에 결정 항목(㉮ 열람 고지/구현 ㉯ 공개 고지·토글) 추가. 기술 상세는 [DEVELOPMENT.md](./DEVELOPMENT.md) 2026-07-21 그레이 존 감사 로그.
- **결정 대기**: 상호주의를 진짜 구현할지 vs 문구만 정직하게 정리할지 / 공개 고지·동의 UX 형태. (수정 X — 감사만.)

### 2026-07-17 — 블라인드 쓰기 결정 (재정의 여부를 쓰는 동안 숨김)
- **결정**: 단어를 쓰는 동안엔 이 단어가 처음인지 재정의인지 **어떤 신호도 주지 않는다**. 기존엔 재정의일 때 "생각의 변화" 입력이 노출되어 사실상 스포일러였음 → 인지하는 순간 일부러 다르게(또는 같게) 쓰게 되어 기록의 순도가 오염된다는 판단. "모르고 썼는데 거의 똑같아서 놀랐다"는 사용자 경험담이 곧 이 제품의 킬러 모먼트 — 그 놀람을 쓰기 전이 아니라 **저장 후**에 배치한다.
- **함께 결정**: "NEW" 배지도 달지 않음(신규에만 붙는 배지는 부재 자체가 재정의 신호가 되어 동일한 스포일러). 변화 노트는 쓰기 시점 입력 제거, 단어 상세 타임라인에서 사후 기록(기존 기능 활용). 저장 직후 "N번째 정의" 리빌 + 지난 생각 비교 진입 추가. 구현은 [DEVELOPMENT.md](./DEVELOPMENT.md) 2026-07-17 참조.
- **추가 결정(같은 날)**: 단어장 행의 "변화" 뱃지 제거 + 변화 통계 기준을 "2회 이상 정의"에서 **사용자가 남긴 변화 노트**로 교체. 기계적 기준은 쓸수록 모든 단어에 붙어 신호가 죽고, 실제로 생각이 안 변한 재정의도 "변화"로 표시되는 거짓 신호였음. 노트 기반이면 사용자가 선언한 변화만 세므로 영구히 의미 유지.
- **후속 논의거리**: 옛 단어를 일부러 다시 띄워주는 "재만남" 추천 설계(회상과는 다른 결).

### 2026-07-17 — 닉네임 정책 확정 (서버 단일 출처 · 로그인 필수 · 디폴트 자동 배정)
- **결정**: 닉네임은 서버가 단일 출처(중복 전역 금지). **편집은 로그인 필수** — 비로그인이 닉네임을 탭하면 로그인 유도(중복 검사가 서버에서만 가능 + 광장 표시명과 100% 일치 보장). 기존 "익명 모델 기본 미설정"(2026-06-02 로그)을 대체: **가입 시 "형용사 명사" 디폴트 닉네임 자동 배정**("산뜻한 밤바람"류) — 신규 유저는 광장에서 '익명' 없이 시작. 빈 값 저장(미설정 복귀)은 여전히 허용.
