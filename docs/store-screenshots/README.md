## 만든 방법

iPhone 16 Pro 원본은 **1206×2622**인데 ASC 6.9" 슬롯은 **1320×2868**을 요구한다.
비율 차이가 **0.065%**(2868px 높이에서 1.9px)라 **자르지 않고 그대로 늘렸다** — 눈에 안 보인다.

```python
from PIL import Image
Image.open(src).convert('RGB').resize((1320, 2868), Image.LANCZOS).save(dst, 'PNG', optimize=True)
```
